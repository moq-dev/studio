# Models

`selfie_segmentation_landscape.onnx` is MediaPipe's selfie segmentation,
landscape variant: 256x144 RGB in `[0, 1]` in, a 256x144 person alpha out.

[onnx-community/mediapipe_selfie_segmentation_landscape](https://huggingface.co/onnx-community/mediapipe_selfie_segmentation_landscape)
at commit `2497d5bec26c626c7b3c4edc6e1fefc21b64f6c3` (`onnx/model.onnx`,
SHA-256 `7a0adcfdb1715d3b0ff0f61486d8a181c33f4a208343a5abfccbc6540e872d24`),
unmodified.
